# 📝 简单 TODO 应用

一个轻量级的 TODO 任务管理应用，使用原生 HTML/CSS/JavaScript 构建。

## ✨ 功能特性

- ✅ 添加新任务
- ✅ 标记任务完成/未完成
- ✅ 删除任务
- ✅ 任务统计（总数和已完成数）
- ✅ 本地存储（刷新后数据不丢失）
- ✅ 响应式设计

## 🚀 快速开始

1. 克隆或下载项目文件
2. 用浏览器打开 `index.html`
3. 开始管理您的任务！

## 📁 文件结构

```
.
├── index.html    # 应用主页面
├── styles.css    # 样式表
├── app.js        # 逻辑脚本
└── README.md     # 本文件
```

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和布局（含渐变、动画）
- **JavaScript ES6** - 应用逻辑和数据管理
- **LocalStorage API** - 本地数据持久化

## 🎨 UI 特点

- 现代化渐变背景
- 流畅的交互动画
- 移动设备适配
- 清晰的视觉反馈

## 📝 使用示例

1. **添加任务**：输入任务文本后点击"添加任务"或按 Enter
2. **完成任务**：勾选复选框标记任务完成
3. **删除任务**：点击"删除"按钮移除任务
